Panduan Penggunaan

Tata cara menganalisis suara untuk memperoleh akurasi optimal

1

Siapkan File Audio

Format yang didukung: WAV, MP3, OGG, FLAC, M4A. Format WAV direkomendasikan karena mempertahankan sinyal gelombang utuh tanpa kompresi.

2

Unggah File

Klik tombol Pilih File atau tarik file audio ke kotak upload yang disediakan.

3

Mulai Analisis

Tekan tombol Analisis Suara dan tunggu beberapa detik sampai sistem selesai memproses.

1

Buka Tab Rekam Suara

Pilih tab Rekam Suara di panel atas dan berikan izin akses mikrofon pada browser.

2

Rekam Audio

Tekan tombol REC untuk mulai merekam. Rekam suara pembicara atau sampel audio minimal 5 hingga 15 detik.

3

Hentikan dan Analisis

Tekan tombol Stop, dengarkan hasil rekaman, lalu tekan tombol Analisis Rekaman.

Kondisi Ideal
  • Durasi audio berkisar antara 5 hingga 30 detik
  • Lingkungan rekaman tenang dan minim derau latar
  • Menggunakan mikrofon yang jernih tanpa distorsi keras
Kondisi Kurang Ideal
  • Durasi audio terlalu singkat (di bawah 3 detik)
  • Rekaman suara tertimpa musik latar atau suara bising
  • File rekaman terkompresi berulang kali dengan bitrate sangat rendah
